## Things I've built

### [Preview](https://github.com/carlocaprini/preview)

*Sharing interactive work without deploying a separate website every time.*

I built Preview because I wanted a simple way to share HTML reports and interactive deliverables. It lets me publish content, create links that expire or can be revoked, attach PDF companions, and see aggregate engagement.

I can manage everything through a web interface or via MCP, including from AI clients and agents.

It's a personal tool I use in production, not a SaaS product. The source code is public for anyone interested in how it works or wanting to run their own instance.

[Explore the project](https://github.com/carlocaprini/preview) · [Self-hosting guide](https://github.com/carlocaprini/preview/blob/main/docs/self-hosting.md)

### [Product & AI Skills](https://github.com/carlocaprini/product-ai-skills)

*Reusable Agent Skills for practical product work.*

When working with AI on product decisions, I want more than a convincing answer. I want to see the assumptions, missing evidence, trade-offs, and boundaries behind it.

I've turned some of these recurring questions into four Agent Skills: reviewing product decisions, assessing agent autonomy, reviewing API changes, and evaluating AI features.

Each skill has its own validation and documented evaluation evidence. The goal is to make these workflows useful and testable, rather than just collecting prompts.

[Explore the skills](https://github.com/carlocaprini/product-ai-skills/tree/main/skills)

## How I work

Most of these projects start with something I need in my own work. I build a version I can use, see where it falls short, and change it.

AI is increasingly part of how I research, plan, implement, and review software. I spend more time defining what needs to happen, checking results, and deciding what is ready. The tools change how the work gets done, but not who is responsible for it.
